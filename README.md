# Muebles Castillo

Sitio web oficial para **Muebles Castillo**, una carpintería artesanal premium ubicada en Mérida, Yucatán, liderada por el artesano Arturo Castillo. Este proyecto destaca la calidad del trabajo en madera sólida y facilita el contacto directo con los clientes.

## 🚀 Funcionalidades Principales

- **Diseño Premium y Responsivo:** Interfaz elegante y adaptable a dispositivos móviles que refleja la calidad de la marca.
- **Sección de Galería:** Muestra visual de proyectos recientes (Repisas, Escritorios, Cabeceras, etc.) con efectos de interacción.
- **Integración con WhatsApp:** Formulario de contacto que redirige automáticamente a una conversación de WhatsApp con un mensaje pre-llenado para agilizar cotizaciones.
- **Mapa Interactivo:** Ubicación exacta del taller mediante Google Maps embebido.
- **Animaciones Suaves:** Efectos de "fade-in" al hacer scroll y desplazamiento suave (smooth scroll) en la navegación.

## 🛠️ Tecnologías

- **HTML5** Semántico
- **CSS3** Moderno (Diseño visual y animaciones)
- **JavaScript** (Lógica del formulario e interactividad)
- **Vite** (Empaquetador y entorno de desarrollo)

## 📋 Características del Negocio

- Carpintería 100% madera sólida.
- Más de 15 años de experiencia.
- Ubicación en Fracc. Las Américas, Mérida.

## 📦 Instalación y Uso

1.  Clonar el repositorio.
2.  Instalar dependencias:
    ```bash
    npm install
    ```
3.  Iniciar el servidor de desarrollo:
    ```bash
    npm run dev
    ```
